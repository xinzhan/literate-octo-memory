# quote-portrait

Custom **quote** block. Purpose: Testimonial quote with a decorative quote mark, highlighted (bold) passage and a cut-out portrait on the right.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: Quote (portrait); row 2: Quotation paragraph(s); highlighted part in strong; row 3: Portrait image; row 4 (optional): Attribution (none visible in source).

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Notes

'quote' is not in the sta-boilerplate library; it follows the standard block-collection quote content model, extended with a portrait row. The highlighted part ('At first I was afraid ... overcame this') is strong (rendered red). Not a heading. No visible attribution.

Use for a single first-person quote with a portrait. Bold text renders in the accent colour.
