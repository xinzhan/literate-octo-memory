# accordion-faq

Custom **accordion** block. Purpose: Narrow FAQ list of collapsible question/answer items with chevrons and dividers.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: question | answer.

### Example

| Accordion Faq |  |
| --- | --- |
| question | answer |

### Guidance

One row per question. Cell 1: question. Cell 2: answer (any rich text). Uses native details/summary, so it works without JS styling and is keyboard accessible. Put the FAQs heading and follow-up links as default content around the block.

## Visual reference

Narrow (~800px) column: centered 'FAQs' heading, 12-item accordion with chevrons and grey dividers, a small white 'Chat with us / Need help?' WhatsApp card, then three left-aligned blue underlined links.
