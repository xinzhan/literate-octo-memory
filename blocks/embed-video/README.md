# embed-video

Custom **embed** block. Purpose: Single full-width 16:9 YouTube embed, lazily loaded; optional poster image gives click-to-play.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: Embed (video); row 2: Optional poster image above the YouTube URL.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)
