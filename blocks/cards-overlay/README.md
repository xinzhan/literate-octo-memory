# cards-overlay

Custom **cards** block. Purpose: Grid of dark image tiles (2 per row on desktop) with a white linked title over the bottom of the image; whole tile is clickable.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: Cards (overlay); row 2..n (one per card): Image | Linked title.
