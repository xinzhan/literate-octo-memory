# cards-link-tile

Custom **cards** block. Purpose: Two-up tiles linking to detail pages, each with a small thumbnail, title and Learn more link.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: thumbnail | title and Learn more link.

### Example

| Cards Link Tile |  |
| --- | --- |
| thumbnail image | title, Learn more link |

### Guidance

One row per tile. Cell 1: thumbnail image. Cell 2: title text and a Learn more link; the first link makes the whole tile clickable.

## Visual reference

Light grey band; centered heading; two white shadowed tiles with a small thumbnail left, title and small 'Learn more' link.

## Supported variations

No variations.
