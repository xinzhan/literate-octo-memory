# cards-icon

Custom **cards** block. Purpose: Row of call-to-action tiles: centred title, line icon, pill button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: Cards (icon); row 2..n (one per card): Icon image | Title, CTA link.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Notes

Title sits above the icon in the source; the block CSS reorders it. Card text cell: title (p strong or h3), CTA link.

Use for 2-3 short CTA tiles with an icon each. Use cards-overlay for image tiles and cards-logo for logo grids.
