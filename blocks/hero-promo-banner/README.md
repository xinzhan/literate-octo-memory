# hero-promo-banner

Custom **hero** block. Purpose: Top-of-page promotional banner: one full-bleed photo with an H1, short offer text and a CTA overlaid on the left.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: background image row, then a content row with H1, offer text and CTA link.

### Example

| Hero Promo Banner |
| --- |
| background image |
| H1 heading, offer paragraph, CTA link |

### Guidance

Use for campaign/promo heroes where the photo fills the block and text sits on the left half. Row 1: background image. Row 2: heading, text, CTA link (bold link = primary button). Extra or merged cells are tolerated; the first image is always the background.

## Visual reference

Full-width 2560x480 promo photo (red Christmas panel left, Apple HomeView device right) with H1, subline and white pill CTA overlaid on the left. The photo background belongs to the hero block, so the section is not colored.
