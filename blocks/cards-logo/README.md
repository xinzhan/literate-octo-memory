# cards-logo

Custom **cards** block. Purpose: Image-only partner logo grid, 4 per row on desktop and 3 on mobile.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: Cards (logo); row 2..n (one per logo): Logo image | (empty).

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Notes

Image-only cards: image cell with the logo (alt = partner name), empty text cell. The logos are not linked in the source.

Use for sponsor/partner logos. Leave the second cell empty; add a link in it only if the logo should link.
