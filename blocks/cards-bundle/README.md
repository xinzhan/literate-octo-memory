# cards-bundle

Custom **cards** block. Purpose: Static 1/2/3-column grid of bundle product cards.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: image | title with price, description, Select link, recontract link.

### Example

| Cards Bundle |  |
| --- | --- |
| image | title with price, description, **Select** link, recontract link |

### Guidance

One row per bundle. Cell 1: image. Cell 2: title with price, short description, bold Select link (button), recontract text link. CTAs align to the card bottom.

## Visual reference

Black band painted with a solid black-bg.png (not a photo), so the section is colored. Centered white H2, three white bundle cards (image, title with price, description, outlined Select button, recontract link).

## Supported variations

No variations.
