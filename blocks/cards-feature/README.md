# cards-feature

Custom **cards** block. Purpose: Two-column grid of feature items with a circular icon disc beside a bold title and paragraph.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: icon image | title and description.

### Example

| Cards Feature |  |
| --- | --- |
| icon image | title, description |

### Guidance

One row per feature. Cell 1: icon/illustration image (optional). Cell 2: bold title (heading or bold paragraph) and description. No card chrome.

## Visual reference

2-column grid of 6 features; each has a large circular light-grey icon disc on the left and bold title + paragraph on the right.

## Supported variations

No variations.
