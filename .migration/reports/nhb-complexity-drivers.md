# NHB museum sites — key migration complexity drivers

Source: the six site analyses and the shared block library (2026-11-06). Figures are measured from the crawl, rendering and block capture; ratings are an assessment.

## Reading the ratings

- **High**: custom features or a large asset / integration surface that needs bespoke build or decisions.
- **Medium**: mostly shared blocks; effort is driven by volume, languages or clean-up.
- **Low**: small, standard-block site — best used as the pilot to prove the shared library and parsers.
